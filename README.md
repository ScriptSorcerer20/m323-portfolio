# Ausgaben-Kalkulierer

## Projektbeschreibung
Diese Applikation ist ein Ausgaben-Kalkulierer auf Basis von Python Flask mit einer SQLite-Datenbank. Benutzer koennen Ausgaben mit Betrag, Kategorie, Datum und Beschreibung erfassen und anschliessend unterschiedlich auswerten.

## Zweck im Unterricht
Dieses Projekt dient als Praxisprojekt fuer das Modul 323 und sollte alle geforderten Kompetenzfelder abdecken.
